HEG

이번 주는 양이 많았다. creturex가 지난 주 깃발만 꽂고 이번 주에 혼자 터졌고, abyss는 Phase 3부터 8까지 밀어붙였다. habiku도 조용히 쌓였다.

creturex

지난 주 init 하나였는데 이번 주에 PR 19개. 0에서 MVP까지 한 주 만에.

Flutter 셋업, Supabase 데이터 모델, Gemini 인식 어댑터, 온보딩, 스캔 HUD, 위치 마스킹, 포획 이력, 오프라인 큐, 다국어(한/영/일), 앱 내 설정, 도감 잠금 해제 애니메이션, 스플래시 화면까지. 뭔가 쭉 늘어놓으니까 많아 보이는데 실제로도 많았다.

카메라로 뭔가를 "발굴"하는 앱이다. 위치를 마스킹해서 좌표는 비공개로, 공유는 되는 구조. 아직 구체적인 그림을 공개하긴 이른데, 방향 자체는 잡혔다.

abyss

지난 주 Phase 1, 2로 공진화 기반을 깔았으면 이번 주는 Phase 3부터 8까지 달렸다.

SELF.md로 봇이 스스로 돌아보고(Phase 3), 에피소드·사실 기억(Phase 4), 스킬 제안 큐(Phase 5), 목표 추적(Phase 6), 크로스봇 위임(Phase 7), 페르소나 드리프트 + 대시보드(Phase 8)까지. 읽어보면 SF처럼 들리는데 다 코드다.

그 사이에 이미지 첨부 인라인 썸네일, 클립보드 붙여넣기, Linear MCP 연동도 들어갔다. abyss에서 Linear 이슈를 바로 다루는 게 되니까 흐름이 끊기지 않는다. SDK 스트리밍 타임아웃 버그도 잡았다.

habiku

LLM 제공사를 MiniMax에서 Claude로 바꿨다. 함수별로 모델을 독립 선택하는 구조라 교체가 깔끔했다.

iOS 홈스크린 위젯이 들어갔고, 설정 섹션 재정비, 데이터 초기화, 데일리 체크인 알림 수정, 다국어(한/영/일)까지. 지난 주에 골격을 다 세웠으니 이번 주는 완성도를 올린 느낌이다. Welcome split-flap 속도도 1.6배 빠르게 했다. 이런 작은 디테일이 은근 중요하다.
